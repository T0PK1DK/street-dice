# Street Dice

Casual street dice / craps game for friends. Player-banked with center pot (table) action and room/side bets.

## Play

Open `index.html` in any browser. No build step or server required.

- Post a center bet (shooter's stake)
- Fade the pot
- Optionally add room bets
- Roll the dice

Come-out: 7 or 11 wins, 2/3/12 loses, other numbers set the point. Then hit the point before 7.

## Rules

See the in-game flow or the original design notes. All action is between players — no house.

Have fun.
